Collaboration
Agents build. Designers refine.
The agent gets the scene to a first version fast. Your team picks it up in the same file and takes it the rest of the way.
Same file The agent builds in the editor your team already uses. Nothing to import or rebuild.
Fully editable Everything it makes is a regular Spline object: select it, restyle it, animate it.
Back and forth Hand the next pass back to the agent, or take over by hand at any point.
Publish
One scene. Web, Apple and Android.
Ship the same file to a website, an iPhone app or an Android app. Each platform gets its own native renderer, so scenes keep their interactivity and performance.
Web WebGPU · WebGL
Publish a link, embed the viewer, or export code for your stack and host it yourself.
Apple Metal
Add a native SwiftUI view to your app, or generate an Xcode project ready for the App Store.
Android Vulkan
Add a native view with Jetpack Compose, or build an APK or App Bundle straight from Spline.
