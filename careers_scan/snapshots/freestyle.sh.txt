What we're building
Freestyle provides infrastructure for developers building AI applications, coding agents, and workflow engines. Our platform includes powerful micro-VMs that start in about 65ms.
We're focused on making infrastructure fast and programmable. That means working at every layer of the stack - from our own hypervisor and kernel optimizations to distributed storage systems and developer-facing APIs.

Systems Engineer
VM Runtime & Low-Level Infrastructure
Full-time
Build the VM runtime that powers Freestyle. We write our own KVM hypervisor in Rust, built around layered copy-on-write memory — checkpoint, fork, and lazy restore all fall out of it. Work on the VMM, virtio device emulation, micro-VM orchestration, and kernel-level optimizations. You'll be designing the lowest-level primitives that everything else depends on.
What you'll do
• Build and optimize VM lifecycle management, forking, and migration
• Work inside our own Rust VMM and the guest kernel to minimize cold-start times
• Design memory management and resource isolation systems
• Extend the copy-on-write memory and disk layering behind checkpoint, fork, and resume
• Debug and profile performance issues at the kernel and hypervisor level
What we're looking for
• Strong systems programming experience in Rust, C, or C++
• Deep understanding of Linux internals, virtualization, or containers
• Experience with KVM, virtio, hypervisor internals, or low-level runtime work
• Track record of shipping performance-critical infrastructure
Rust KVM Virtualization Linux Kernel
