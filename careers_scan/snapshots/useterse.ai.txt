Every resource and Agent gets its own little home.
Give each resource its own co-located micro-VM and SQLite database, coordinate edits from agents and humans without worrying about race conditions.
Build your actor, deploy it, add it to your product. That's it.
Step 1 : Define your actor
Use our declarative API to build your actor. The methods become the RPC client, the generics become the API types, and @Persisted or this.db.exec() persist state.

Step 2 : Deploy it
Run it locally while you build, then ship it to Terse Cloud with one command. Once it's deployed, your actors are reachable from anywhere in the world.

Anatomy of a Durable Actor
Every tiny server bundles its own compute, SQLite database and WebSocket server, and streams every write to GCS Rapid storage so nothing is lost.
Observability built in.
Every actor gets a live dashboard: request rate, queue wait and run time, each RPC call, and every WebSocket connection over its lifetime.
