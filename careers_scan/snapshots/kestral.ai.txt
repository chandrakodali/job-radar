Get Started
Paste this into your coding agent
Cursor, Claude Code, or Codex installs the Kestral plugin and reports any remaining activation steps.
Install the Kestral plugin in this app, then connect and start a first plan.
1. Download the installer:
curl -fsSL https://raw.githubusercontent.com/Kestral-Team/kestral-plugins/main/setup.sh --create-dirs -o ~/.kestral/setup.sh
2. After the download succeeds, run it with --app set to your current app: cursor, claude-code, or codex:
bash ~/.kestral/setup.sh --app <app>
Let me know any steps I need to take next.
The install enables sync hooks. They nudge your agent after push and PR so Kestral stays in the loop without you remembering to ask.
Prefer Terminal?
macOS and Linux. This opens a host menu. The paste above is the advertised path — it already passes --app.
curl -fsSL https://raw.githubusercontent.com/Kestral-Team/kestral-plugins/main/setup.sh | bash
After install
Pick your app for the first step after the paste. The paste is the same on every host — your agent fills --app.
Claude Code Setup steps
Already pasted the install prompt? Start here.
Load kestral-setup
In the terminal: run /reload-plugins, then /kestral:kestral-setup. In the Claude desktop app: quit and reopen so the plugin appears, open Customize → Plugins → Yours → Kestral, click Connect in Connectors, then quit and reopen once more and run /kestral:kestral-setup in a new chat.
